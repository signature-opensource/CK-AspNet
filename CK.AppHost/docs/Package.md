The bootstrap of a CKomposable application host, the same for every party.

The host project "XXX.Host" references this package and its `Program.cs` is one line:
`await CK.Core.CKomposableAppHost.RunAsync( args );`. It loads the code generated by its "XXX.Builder", configures the
monitoring and the application identity, and runs as a Windows service or a systemd service when started as one. The
package also carries the MSBuild conventions of the host project (the generated code, the `Clients` folder, the checks).

Main type: `CKomposableAppHost` (`RunAsync`, and `Build` for the tests).

See the [README](https://github.com/signature-opensource/CK-AspNet/blob/stable/CK.AppHost/README.md).
