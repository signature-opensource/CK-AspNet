The bootstrap of a CKomposable application host, the same for every party.

The host project "XXX.Host" references this package and its `Program.cs` is one line:
`return CK.Core.CKomposableAppHost.Run( args );`. It loads the code generated by its "XXX.Builder", configures the
monitoring and the application identity, resolves the secret handles of the configuration, and runs as a Windows service
or a systemd service when started as one. A package of the App can run the host itself (an `IAppHostRunner`: a desktop
window, for instance). The package also carries the MSBuild conventions of the host project (the generated code, the
`Clients` folder, the checks).

Main types: `CKomposableAppHost` (`Run`, and `Build` for the tests), `IAppHostRunner`.

See the [README](https://github.com/signature-opensource/CK-AspNet/blob/stable/CK.AppHost/README.md).
